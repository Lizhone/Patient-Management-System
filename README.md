
# Gentle Care – Patient Management System

Gentle Care is a web-based Patient Management System designed to simplify hospital administrative operations by providing a centralized platform for managing patient records and billing activities.

The application enables hospital staff to register patients, maintain medical information, monitor patient statistics, generate bills, and track payment statuses through an intuitive and user-friendly interface.

## Features

### Staff Authentication
- Secure staff login.
- JWT-based authentication.
- Protected staff access.

### Dashboard
- Overview of total patients.
- New patient tracking.
- Total bills generated.
- Active patient records.
- Quick navigation to major modules.

### Patient Management
- Register new patients.
- View complete patient information.
- Search and filter patient records.
- Update existing patient details.
- Delete patient records.
- Track newly registered patients awaiting review.

### Billing Management
- Generate multiple bills for individual patients.
- Select patients from existing records.
- Add service descriptions and billing amounts.
- Manage payment methods.
- Track payment statuses:
  - Paid
  - Pending
  - Partially Paid
- View billing history.
- Monitor paid revenue and pending amounts.

## Database

The application uses Microsoft SQL Server to store and manage:

- Staff information
- Patient personal information
- Medical history
- Patient billing records
- Payment status and billing details

## Application Workflow

1. Staff logs into the system.
2. The dashboard displays patient and billing statistics.
3. Staff registers new patients.
4. Patient records can be viewed, searched, updated, and deleted.
5. Staff generates bills for registered patients.
6. Payment information and billing history are maintained.
7. Dashboard statistics reflect the stored records.

## Project Objective

The goal of Gentle Care is to improve the efficiency of hospital administrative workflows by reducing manual record management, organizing patient information, and simplifying billing operations through a centralized web application.

## Developer

Developed as a full-stack web application using Angular, Python Flask, and Microsoft SQL Server.
